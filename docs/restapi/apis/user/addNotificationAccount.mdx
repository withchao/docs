<center>

## Add Notification Account

</center>

### 简要描述

- 新增系统号；通知号无法获取 `token`

### 请求方式

- `POST`

### 请求 URL

- `/user/add_notification_account`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "appMangerLevel": 3,
  "faceURL": "url",
  "nickName": "notification1",
  "userID": "userID"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 可选 | string | 通知号 ID |
| nickName | 必填 | string | 通知号昵称 |
| faceURL | 必填 | string | 通知号头像 |
| appMangerLevel | 必填 | int32 | 3或4 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "appMangerLevel": 0,
    "faceURL": "string",
    "nickName": "string",
    "userID": "string"
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [addNotificationAccountResp](#ref-openim-user-addnotificationaccountresp) | 通用数据对象，具体结构见下方数据结构 |

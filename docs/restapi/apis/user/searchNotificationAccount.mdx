<center>

## Search Notification Account

</center>

### 简要描述

- 获取所创建的系统号（通知号、机器人）列表，包括 ID、头像和名称。

### 请求方式

- `POST`

### 请求 URL

- `/user/search_notification_account`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "appManagerLevel": 0,
  "keyword": "string",
  "pagination": {
    "pageNumber": "1",
    "showNumber": "10"
  }
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| keyword | 可选 | string | 填写 userID 或 nickname，不填时默认返回对应分页的系统号 |
| appManagerLevel | 必填 | optional int32 (oneof _appManagerLevel) |  |
| pagination | 必填 | [RequestPagination](#ref-openim-sdkws-requestpagination) | 分页参数结构体 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "notificationAccounts": [
      {
        "appMangerLevel": 0,
        "faceURL": "string",
        "nickName": "string",
        "userID": "string"
      }
    ],
    "total": 0
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [searchNotificationAccountResp](#ref-openim-user-searchnotificationaccountresp) | 通用数据对象，具体结构见下方数据结构 |

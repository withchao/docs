## Append Stream Msg

</center>

### 简要描述

- msg 服务接口定义。

### 请求方式

- `POST`
- `PUT`

### 请求 URL

- `/msg/append_stream_msg`
- `/msg/append_stream_msg`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "clientMsgID": "string",
  "conversationID": "string",
  "end": false,
  "packets": [
    "string"
  ],
  "startIndex": 0
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| conversationID | 必填 | string |  |
| clientMsgID | 必填 | string |  |
| startIndex | 必填 | int64 |  |
| packets | 必填 | []string |  |
| end | 必填 | bool |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

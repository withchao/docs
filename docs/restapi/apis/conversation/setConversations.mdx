<center>

## Set Conversations

</center>

### 简要描述

- 多个用户对同一会话可选择性的设置字段。

### 请求方式

- `POST`

### 请求 URL

- `/conversation/set_conversations`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "conversation": {
    "attachedInfo": "attached",
    "burnDuration": "30",
    "conversationID": "si_4365007572_6965946400",
    "conversationType": "1",
    "isPinned": "false",
    "isPrivateChat": "true",
    "recvMsgOpt": "0",
    "userID": "4365007572"
  },
  "userIDs": [
    "6965946400"
  ]
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userIDs | 必填 | []string | 要设置会话字段的用户ID列表 |
| conversation | 必填 | [ConversationReq](#ref-openim-conversation-conversationreq) | 会话对象 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

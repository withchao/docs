## Get Sorted Conversation List

</center>

### 简要描述

- 根据是否置顶、发消息的时间先后获取排序后的会话列表。

### 请求方式

- `POST`

### 请求 URL

- `/conversation/get_sorted_conversation_list`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "conversationIDs": [
    "si_2699373280_9906953281"
  ],
  "pagination": {
    "pageNumber": "1",
    "showNumber": "20"
  },
  "userID": "9906953281"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string | 当前用户ID |
| conversationIDs | 可选 | []string | 会话ID列表，填写后返回指定的会话列表，不填返回默认分页的会话列表 |
| pagination | 必填 | [RequestPagination](#ref-openim-sdkws-requestpagination) | 分页参数结构体 |

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [GetSortedConversationListResp](#ref-openim-conversation-getsortedconversationlistresp) | 通用数据对象，具体结构见下方数据结构 |

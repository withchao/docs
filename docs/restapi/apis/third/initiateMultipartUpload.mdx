<center>

## Initiate Multipart Upload

</center>

### 简要描述

- 三方服务接口，提供对象存储、推送、日志等功能。

### 请求方式

- `POST`

### 请求 URL

- `/object/initiate_multipart_upload`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "cause": "string",
  "contentType": "string",
  "hash": "string",
  "maxParts": 0,
  "name": "string",
  "partSize": 0,
  "size": 0,
  "urlPrefix": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| hash | 必填 | string |  |
| size | 必填 | int64 |  |
| partSize | 必填 | int64 |  |
| maxParts | 必填 | int32 |  |
| cause | 必填 | string |  |
| name | 必填 | string |  |
| contentType | 必填 | string |  |
| urlPrefix | 必填 | string |  |

        ],

          {

              {
                "key": "string",

                "key": "string",

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [InitiateMultipartUploadResp](#ref-openim-third-initiatemultipartuploadresp) | 通用数据对象，具体结构见下方数据结构 |

<center>

## Remove Participants

</center>

### 简要描述

- batch remove participant out of the meeting room

### 请求方式

- `POST`

### 请求 URL

- `/rtc-meeting/remove_participants`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "meetingID": "string",
  "participantUserIDs": [
    "string"
  ],
  "userID": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| meetingID | 必填 | string |  |
| userID | 必填 | string |  |
| participantUserIDs | 必填 | []string |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "failedUserIDList": [
      "string"
    ],
    "successUserIDList": [
      "string"
    ]
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [RemoveMeetingParticipantsResp](#ref-openmeeting-meeting-removemeetingparticipantsresp) | 通用数据对象，具体结构见下方数据结构 |

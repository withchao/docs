<center>

## Kick Group Member

</center>

### 简要描述

- 将群成员从群组中移除。如果要移除群主，先转让群主身份。

### 请求方式

- `POST`

### 请求 URL

- `/group/kick_group`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "deleteMember": false,
  "groupID": "2137448827",
  "kickedUserIDs": [
    "2137448827"
  ],
  "reason": "nihao",
  "sendMessage": false
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| groupID | 必填 | string | 群ID |
| kickedUserIDs | 必填 | []string | 被移除群的用户ID列表 |
| reason | 可选 | string | 被移除群的原因 |
| sendMessage | 必填 | optional bool (oneof _sendMessage) |  |
| deleteMember | 必填 | bool |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

<center>

## Set Group Info Ex

</center>

### 简要描述

- 修改群组信息。仅传需要修改的字段，也支持零值。

### 请求方式

- `POST`

### 请求 URL

- `/group/set_group_info_ex`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "applyMemberFriend": 1,
  "displayIsRead": false,
  "ex": "new ex",
  "faceURL": "www.newfaceURL.com",
  "groupID": "xadxwr24",
  "groupName": "new name",
  "introduction": "new introduction",
  "lookMemberInfo": 1,
  "needVerification": 1,
  "notification": "new notification"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| groupID | 必填 | string | 要修改的群ID |
| groupName | 可选 | *string | 新群名 |
| notification | 可选 | *string | 新群公告 |
| introduction | 可选 | *string | 新群介绍 |
| faceURL | 可选 | *string | 新群头像 |
| ex | 可选 | *string | 新群扩展字段 |
| needVerification | 可选 | *int32 | 进群是否需要验证；0：申请加入群需要同意，成员邀请可直接进群，1：所有人进群需要验证，除了群主管理员邀请进群，2：直接进群 |
| lookMemberInfo | 可选 | *int32 | 是否能查看其他群成员信息；0：允许查看群成员信息，1：不允许查看群成员信息 |
| applyMemberFriend | 可选 | *int32 | 群成员是否能添加好友；0：允许从群成员处添加好友，1：不允许添加 |
| displayIsRead | 可选 | *bool |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

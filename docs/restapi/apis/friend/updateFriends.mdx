<center>

## Update Friends

</center>

### 简要描述

- 修改指定用户（ownerUserID）的某个好友（friendUserID）的备注、星标信息。仅传需要修改的字段，也支持零值。

### 请求方式

- `POST`

### 请求 URL

- `/friend/update_friends`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "ex": "ex",
  "friendUserIDs": [
    "string"
  ],
  "isPinned": true,
  "ownerUserID": "11111111",
  "remark": "remark"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| ownerUserID | 必填 | string | 为该用户的好友设置字段 |
| friendUserIDs | 必填 | []string |  |
| isPinned | 可选 | *bool | 是否星标 |
| remark | 可选 | *string | 备注内容 |
| ex | 可选 | *string | 扩展字段 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

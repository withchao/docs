<center>

## Import Friends

</center>

### 简要描述

- 让指定用户（ownerUserID）和多个用户（friendUserIDs）建立双向好友关系。

### 请求方式

- `POST`

### 请求 URL

- `/friend/import_friend`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "friendUserIDs": [
    "4776986466"
  ],
  "ownerUserID": "2778222451"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| ownerUserID | 必填 | string | 指定的用户 ID |
| friendUserIDs | 必填 | []string | 指定的好友 ID 列表 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

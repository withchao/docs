## Get Incremental Recv Friend Requests

</center>

### 简要描述

- friend 服务接口定义。

### 请求方式

- `POST`

### 请求 URL

- `/friend/get_incremental_recv_friend_requests`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "userID": "string",
  "version": 0,
  "versionID": "string"
}
```

#### GetIncrementalRecvFriendRequestsResp

<a id="ref-openim-sdkws-friendrequest"></a>

#### FriendRequest

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| fromUserID | 必填 | string | 申请人用户ID |
| fromNickname | 必填 | string | 申请人昵称 |
| fromFaceURL | 必填 | string | 申请人头像URL |
| toUserID | 必填 | string | 被申请人用户ID |
| toNickname | 必填 | string | 被申请人昵称 |
| toFaceURL | 必填 | string | 被申请人头像URL |
| handleResult | 必填 | [HandleResult](#ref-openim-sdkws-handleresult) | 处理结果 |
| reqMsg | 必填 | string | 申请消息 |
| createTime | 必填 | int64 | 申请时间（毫秒） |
| handlerUserID | 必填 | string | 处理人用户ID |
| handleMsg | 必填 | string | 处理消息 |
| handleTime | 必填 | int64 | 处理时间（毫秒） |
| ex | 必填 | string | 好友请求扩展字段 |

<a id="ref-openim-sdkws-handleresult"></a>

#### HandleResult

| 名称 | 值 | 说明 |
| :--- | :--- | :--- |
| HandleResultDefault | 0 | wait request handle. |
| HandleResultDecline | -1 | decline the request. |
| HandleResultAccept | 1 | accept the request. |

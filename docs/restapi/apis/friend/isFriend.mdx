<center>

## Is Friend

</center>

### 简要描述

- 检查两个用户是否存在好友关系。

### 请求方式

- `POST`

### 请求 URL

- `/friend/is_friend`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "userID1": "11111111",
  "userID2": "11111112"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID1 | 必填 | string | 用户 ID |
| userID2 | 必填 | string | 用户 ID |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "inUser1Friends": false,
    "inUser2Friends": false
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [isFriendResp](#ref-openim-relation-isfriendresp) | 通用数据对象，具体结构见下方数据结构 |

### 数据结构

<a id="ref-openim-relation-isfriendreq"></a>

#### isFriendReq

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID1 | 必填 | string | 用户 ID |
| userID2 | 必填 | string | 用户 ID |

<a id="ref-openim-relation-isfriendresp"></a>

#### isFriendResp

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| inUser1Friends | 必填 | bool | If userID2 is in userID1’s friend list, return true |
| inUser2Friends | 必填 | bool | If userID1 is in userID2’s friend list, return true |

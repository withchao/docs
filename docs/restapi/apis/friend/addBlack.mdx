<center>

## Add Black

</center>

### 简要描述

- 将 blackUserID 添加到 ownerUserID 的黑名单中，blackUserID 不能再给 ownerUserID 发送消息。

### 请求方式

- `POST`

### 请求 URL

- `/friend/add_black`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "blackUserID": "11111113",
  "ex": "ex",
  "ownerUserID": "11111111"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| ownerUserID | 必填 | string | 为此用户添加黑名单 |
| blackUserID | 必填 | string | 被拉黑的用户 ID |
| ex | 可选 | string | 扩展字段 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

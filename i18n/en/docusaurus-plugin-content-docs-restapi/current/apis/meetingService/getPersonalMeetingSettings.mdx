<center>

## Get Personal Meeting Settings

</center>

### 简要描述

- Gets personal meeting settings.

### 请求方式

- `POST`

### 请求 URL

- `/rtc-meeting/get_personal_setting`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "meetingID": "string",
  "userID": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| meetingID | 必填 | string |  |
| userID | 必填 | string |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "setting": {
      "cameraOnEntry": false,
      "microphoneOnEntry": false
    }
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [GetPersonalMeetingSettingsResp](#ref-openmeeting-meeting-getpersonalmeetingsettingsresp) | 通用数据对象，具体结构见下方数据结构 |

### 数据结构

<a id="ref-openmeeting-meeting-getpersonalmeetingsettingsreq"></a>

#### GetPersonalMeetingSettingsReq

Request to get personal meeting settings.

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| meetingID | 必填 | string |  |
| userID | 必填 | string |  |

<a id="ref-openmeeting-meeting-getpersonalmeetingsettingsresp"></a>

#### GetPersonalMeetingSettingsResp

Response with personal meeting settings.

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| setting | 必填 | [PersonalMeetingSetting](#ref-openmeeting-meeting-personalmeetingsetting) |  |

<a id="ref-openmeeting-meeting-personalmeetingsetting"></a>

#### PersonalMeetingSetting

Personal meeting settings related to video and audio on entry.

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| cameraOnEntry | 必填 | bool | Whether the camera should be enabled by default when joining the meeting. |
| microphoneOnEntry | 必填 | bool | Whether the microphone should be enabled by default when joining the meeting. |

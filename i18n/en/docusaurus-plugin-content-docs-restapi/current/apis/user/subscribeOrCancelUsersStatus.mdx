## Subscribe Or Cancel Users Status

</center>

### 简要描述

- 订阅或取消订阅指定用户在线状态。

### 请求方式

- `POST`

### 请求 URL

- `/user/subscribe_users_status`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "genre": 0,
  "userID": "string",
  "userIDs": [
    "string"
  ]
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string | 指定用户 ID（订阅关系的发起者）。 |
| userIDs | 必填 | []string | 目标用户 ID 列表。 |
| genre | 必填 | int32 | 操作类型：1 订阅，2 取消订阅。 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "statusList": [
      {
        "platformIDs": [
          0
        ],
        "status": 0,
        "userID": "string"
      }
    ]
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [subscribeOrCancelUsersStatusResp](#ref-openim-user-subscribeorcancelusersstatusresp) | 通用数据对象，具体结构见下方数据结构 |

| 字段名 | 选填 | 类型 | 说明 |

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |

| status | 必填 | int32 | 在线状态：1 在线，0 离线。 |

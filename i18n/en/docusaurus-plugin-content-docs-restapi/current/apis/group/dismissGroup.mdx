<center>

## Dismiss Group

</center>

### 简要描述

- 解散群，解散后无法恢复。

### 请求方式

- `POST`

### 请求 URL

- `/group/dismiss_group`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "deleteMember": false,
  "groupID": "2137448827",
  "sendMessage": false
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| groupID | 必填 | string | 群ID |
| deleteMember | 可选 | bool | 是否删除群成员信息 |
| sendMessage | 必填 | optional bool (oneof _sendMessage) |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

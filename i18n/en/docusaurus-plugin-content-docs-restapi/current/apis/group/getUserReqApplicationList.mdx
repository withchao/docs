## Get User Req Application List

</center>

### 简要描述

- 获取指定用户申请入群的所有申请列表，按时间按排序。

### 请求方式

- `POST`

### 请求 URL

- `/group/get_user_req_group_applicationList`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "groupIDs": [
    "string"
  ],
  "handleResults": [
    0
  ],
  "pagination": {
    "pageNumber": "1",
    "showNumber": "100"
  },
  "userID": "1225441072"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| pagination | 必填 | [RequestPagination](#ref-openim-sdkws-requestpagination) | 分页参数结构体 |
| userID | 必填 | string | 用户ID |
| groupIDs | 必填 | []string |  |
| handleResults | 必填 | []int32 |  |

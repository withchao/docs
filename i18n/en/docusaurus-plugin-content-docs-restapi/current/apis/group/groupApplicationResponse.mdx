## Group Application Response

</center>

### 简要描述

- 处理入群申请，同意和拒绝某人进群。

### 请求方式

- `POST`

### 请求 URL

- `/group/group_application_response`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "fromUserID": "string",
  "groupID": "xadxwr24",
  "handleResult": 1,
  "handledMsg": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| groupID | 必填 | string | 群ID |
| fromUserID | 必填 | string |  |
| handledMsg | 可选 | string | 处理信息 |
| handleResult | 必填 | int32 | 处理结果；-1：拒绝该用户加群，1：同意用户加群 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": ""
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |

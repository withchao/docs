## Signal Get Rooms

</center>

### 简要描述

- Signal 服务接口定义。

### 请求方式

- `POST`

### 请求 URL

- `/rtc-meeting/signal_get_rooms`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "roomIDs": [
    "string"
  ]
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| roomIDs | 必填 | []string |  |

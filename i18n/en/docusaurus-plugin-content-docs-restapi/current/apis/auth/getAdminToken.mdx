<center>

## Get Admin Token

</center>

### 简要描述

- 通过secret获取管理员token

### 请求方式

- `POST`

### 请求 URL

- `/auth/get_admin_token`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |

### 请求参数示例

```json
{
  "secret": "openIM123",
  "userID": "imAdmin"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| secret | 必填 | string | 密钥，config/share.yaml 中 secret 字段 |
| userID | 必填 | string | APP管理员ID，默认为为`imAdmin` |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "expireTimeSeconds": 7776000,
    "token": "eyJhbG...5f3Kx9"
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [getAdminTokenResp](#ref-openim-auth-getadmintokenresp) | 通用数据对象，具体结构见下方数据结构 |

### 数据结构

<a id="ref-openim-auth-getadmintokenreq"></a>

#### getAdminTokenReq

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| secret | 必填 | string | 密钥，config/share.yaml 中 secret 字段 |
| userID | 必填 | string | APP管理员ID，默认为为`imAdmin` |

<a id="ref-openim-auth-getadmintokenresp"></a>

#### getAdminTokenResp

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| token | 必填 | string | jwt token值 |
| expireTimeSeconds | 必填 | int64 | token 的过期时间（单位秒）。 |

<center>

## Parse Token

</center>

### 简要描述

- 解析token，获取用户ID和平台ID等信息。

### 请求方式

- `POST`

### 请求 URL

- `/auth/parse_token`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |

### 请求参数示例

```json
{
  "token": "eyJhbG...5f3Kx9"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| token | 必填 | string | jwt token值 |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "expireTimeSeconds": 7776000,
    "platformID": 1,
    "userID": "123456789"
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [parseTokenResp](#ref-openim-auth-parsetokenresp) | 通用数据对象，具体结构见下方数据结构 |

### 数据结构

<a id="ref-openim-auth-parsetokenreq"></a>

#### parseTokenReq

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| token | 必填 | string | jwt token值 |

<a id="ref-openim-auth-parsetokenresp"></a>

#### parseTokenResp

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string | 用户ID |
| platformID | 必填 | [Platform](#ref-openim-sdkws-platform) | 用户登录时的终端平台 |
| expireTimeSeconds | 必填 | int64 | token 的过期时间（单位秒）。 |

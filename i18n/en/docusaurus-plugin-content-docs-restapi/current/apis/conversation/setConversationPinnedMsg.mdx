<center>

## Set Conversation Pinned Msg

</center>

### 简要描述

- Conversation 服务定义了与会话相关的 RPC 方法。

### 请求方式

- `POST`

### 请求 URL

- `/conversation/set_conversation_pinned_msg`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "conversationID": "string",
  "pinned": false,
  "seq": 0,
  "userID": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string |  |
| conversationID | 必填 | string |  |
| seq | 必填 | int64 |  |
| pinned | 必填 | bool |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "createTime": 0,
    "pinnedTime": 0,
    "version": 0
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [SetConversationPinnedMsgResp](#ref-openim-conversation-setconversationpinnedmsgresp) | 通用数据对象，具体结构见下方数据结构 |

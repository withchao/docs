## Get Incremental Conversation

</center>

### 简要描述

- Conversation 服务定义了与会话相关的 RPC 方法。

### 请求方式

- `POST`

### 请求 URL

- `/conversation/get_incremental_conversations`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "userID": "string",
  "version": 0,
  "versionID": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string |  |
| versionID | 必填 | string |  |
| version | 必填 | uint64 |  |

## Get Conversations Has Read And Max Seq

</center>

### 简要描述

- msg 服务接口定义。

### 请求方式

- `POST`

### 请求 URL

- `/msg/get_conversations_has_read_and_max_seq`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "conversationIDs": [
    "string"
  ],
  "returnPinned": false,
  "userID": "string"
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| userID | 必填 | string |  |
| conversationIDs | 必填 | []string |  |
| returnPinned | 必填 | bool |  |

### 成功返回示例

```json
{
  "errCode": 0,
  "errMsg": "",
  "errDlt": "",
  "data": {
    "pinnedConversationIDs": [
      "string"
    ],
    "seqs": {
      "string": {
        "hasReadSeq": 0,
        "maxSeq": 0,
        "maxSeqTime": 0,
        "subtractUnread": 0
      }
    }
  }
}
```

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [GetConversationsHasReadAndMaxSeqResp](#ref-openim-msg-getconversationshasreadandmaxseqresp) | 通用数据对象，具体结构见下方数据结构 |

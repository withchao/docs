<center>

## Search Message

</center>

### 简要描述

- msg 服务接口定义。

### 请求方式

- `POST`

### 请求 URL

- `/msg/search_msg`

### Header

| header 名 | 示例值 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| operationID | 1646445464564 | 必填 | string | 用于全局链路追踪，建议使用时间戳，在每个请求中独立 |
| token | eyJhbxxxx3Xs | 必填 | string | 接口鉴权 token |

### 请求参数示例

```json
{
  "contentType": 0,
  "pagination": {
    "pageNumber": 0,
    "showNumber": 0
  },
  "recvID": "string",
  "sendID": "string",
  "sendTime": "string",
  "sessionType": 0
}
```

| 字段名 | 选填 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| sendID | 必填 | string | sender ID |
| recvID | 必填 | string | receiver ID |
| contentType | 必填 | int32 | 消息类型：<br />101 文本，102 图片，103 音频，104 视频，105 文件，110 自定义，1400 系统通知。 |
| sendTime | 必填 | string |  |
| sessionType | 必填 | int32 |  |
| pagination | 必填 | [RequestPagination](#ref-openim-sdkws-requestpagination) |  |

  "data": {
    "chatLogs": [
      {
        "chatLog": {
          "clientMsgID": "string",
          "content": "string",
          "contentType": 0,
          "createTime": 0,

          "groupFaceURL": "string",
          "groupID": "string",
          "groupMemberCount": 0,
          "groupName": "string",
          "groupOwner": "string",
          "groupType": 0,
          "msgFrom": 0,
          "recvID": "string",

### 成功返回示例的参数说明

| 参数名 | 类型 | 说明 |
| :--- | :--- | :--- |
| errCode | int | 错误码，0表示成功 |
| errMsg | string | 错误简要信息，成功时为空 |
| errDlt | string | 错误详细信息，成功时为空 |
| data | [SearchMessageResp](#ref-openim-msg-searchmessageresp) | 通用数据对象，具体结构见下方数据结构 |
